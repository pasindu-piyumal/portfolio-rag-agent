# Projects

## 1. BrainTumerAI – Brain MRI Tumor Classification

### Technologies
Python, TensorFlow, Keras, Convolutional Neural Networks (CNNs), NumPy, Pandas, Scikit-learn, OpenCV, Pillow, Matplotlib, Seaborn.

### Description
Developed a deep learning model using Convolutional Neural Networks (CNNs) to classify brain MRI images into four categories:
- Glioma
- Meningioma
- Pituitary tumor
- No tumor

### Repository
https://github.com/pasindu-piyumal/BrainTumerAI

## 2. SLFloodWatch – Sri Lanka Flood Risk Prediction & Monitoring System

### Technologies
Python, Django, Pandas, NumPy, Scikit-learn, Random Forest, SQLite, HTML, CSS, JavaScript, Chart.js, Git, GitHub, RiverWatch API.

### Description
Developed a web-based flood risk monitoring and prediction system using machine learning models to classify flood risk levels based on environmental, weather, geographical, and historical flood-related features.

Developed a Django-based web application with:
- Dashboards
- Location monitoring and filtering
- Flood risk prediction
- Real-time river level monitoring

### Repository
https://github.com/pasindu-piyumal/SLFloodWatch
